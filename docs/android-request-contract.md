# Request bounds and cancellation

Run synchronous AIDL calls on a worker thread. All expensive requests have a 120-second coroutine deadline. Local generation also has its native-event deadline; cloud HTTP calls have a 60-second total call timeout. `REQUEST_TIMEOUT`, `REQUEST_CANCELLED`, `GENERATION_TIMEOUT`, and `RATE_LIMITED` are distinct errors. A generation timeout may include partial text. Cloud HTTP 429 maps to `RATE_LIMITED`; nullable response usage is optional.

`getServiceInfo` advertises `supportsCancellation: true`. Only when that flag is present, a client can call the appended `cancelCurrentRequest(protocolVersion)` AIDL method from another thread. This cancels that UID's currently registered operation, returning `cancelled: false` if none exists. It cannot cancel another UID's request. Because each UID has at most one active operation, no client-supplied request ID is needed. Cancellation is a best-effort signal: it closes cloud sockets and stops local generation. ONNX execution, file parsing, and native model loading have non-suspending sections which must return before cleanup completes. Their native work is not forcibly terminated. Retain the worker thread until the original call returns; do not assume cancellation acknowledgement means resources are already released.

Text classification/translation accept up to 32,768 UTF-16 characters. Adapter IDs and versions accept 256. Local prompts accept 8,192 characters, 1–2,048 output tokens and finite temperature 0–2. Message arrays accept 1–128 objects and at most 65,536 characters. Cloud structured content is supported; local chat rejects it through the Qwen text-only validator. Optional system/tools payloads, auth tokens and cache keys are also bounded before use. Model context limits still apply independently of character limits.

AIDL transaction numbers for existing methods are preserved by appending the cancellation method. Older services must never receive the new transaction without discovery. Cancellation/deadline registry, generation bounds, malformed schema, nullable usage and socket cancellation have JVM regressions. End-to-end Binder/native cancellation latency needs device measurement.
